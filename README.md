## ⁉️ Frågor.

### Vad är skilnden mellan git add och git commit?
när man använder _git add_ så läggs de ändrade filarna i 'Staging area' medan _git commit_ sparar dessa ändringar i git. 

### Varför använder man branches istället för att jobba direkt i main? 
Efter att man har skapat huvudstrukturen så vill man oftast inte göra ändringar till den, då använder man olicka **branches** för att kunna utveckla och testa nya funktioner utan att göra ändringar till huvudstruturen **main**. 

### Vad händer när man gör en merge? 
När man gör en mearge så slår man ihop ändringarna från en branch med en annan branch. 

### Vad är skillnaden mellan att pusha till GitHub och att publicera på Netlify?

Att **pusha till GitHub** betyder att man laddar upp sina kod ändringar och filarna som man har lokalt till GitHub. Man kan göra webbplatsn tillgänglig när man **publicerar på Netlify**.

### Hur exkluderar man en fil från versionshanteringen?

Man änvender filen **.gitignore** där man kan skriva namnet på filen man vil exludera.
